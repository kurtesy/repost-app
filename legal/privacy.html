01

What this tool is

This is a personal, self-hosted application. It runs on the operator's own computer, is not distributed to other users, and has no public sign-up. It exists to repost the operator's own historical Instagram Reels and video posts — unmodified, with the same video file, caption text, and hashtags — to the operator's own YouTube and TikTok accounts.

No other person's Instagram, YouTube, or TikTok account is ever connected to, read from, or posted to by this tool.

02

Data it reads

When the operator connects their Instagram Business or Creator account, the tool retrieves only the following, and only for that one account:

  • Media files — the video content of Reels and video posts.
  • Captions — the exact caption text as written, including hashtags.
  • Post metadata — publish timestamp, permalink, and thumbnail image, used only to display the post list in the dashboard.

It does not read direct messages, comments, followers/following lists, insights/analytics, or any data belonging to accounts other than the one the operator connects.

03

How data is used

Each piece of data is used for exactly one purpose: reproducing the same post on another platform the operator also owns.

Read
Pull video, caption, hashtags from Instagram
Map
Caption → YouTube title/description/tags, or TikTok caption
Post
Upload the same video file to the destination platform
Log
Record success/failure locally, so nothing is ever posted twice

Data is never used for advertising, profiling, analytics products, or any purpose beyond this repost function.

04

Where data lives

All data — downloaded video files, captions, access tokens, and the log of what's been posted where — is stored in a local database file and folder on the operator's own machine. None of it is uploaded to any server operated by the developer, because no such server exists. The only network calls this tool makes are directly between the operator's machine and Instagram, YouTube, or TikTok's own APIs, authenticated as the operator.

05

Third parties

Data is shared with exactly three parties, and only because they are the destination of the repost the operator initiated:

  • Meta / Instagram Graph API — source of the media and captions.
  • Google / YouTube Data API — destination for reposted video, title, description, and tags.
  • TikTok Content Posting API — destination for reposted video and caption.

No data is sold, rented, or provided to any advertiser, data broker, or analytics service.

06

Platform permissions

The Instagram connection requests the following scopes. Each is used for exactly the purpose listed — no scope is requested speculatively or for future use.

ScopeAccessUsed for
instagram_basic read Listing the connected account's own media (video URL, caption, timestamp, thumbnail) via its linked Facebook Page.
pages_show_list read Locating the Facebook Page connected to the Instagram Business account, once, during setup.
pages_read_engagement read Required alongside pages_show_list to obtain a valid Page access token; engagement metrics themselves are never read or stored.
pages_read_user_content read Required dependency of instagram_basic for reading the Page's own content.
business_management read Confirming the Page's Business Manager association where Meta requires it to issue a Page access token.
No publish-back scope is requested. This tool never posts, edits, or deletes anything on Instagram — it only reads. YouTube and TikTok connections use each platform's standard upload/publish scope, used only to upload the reposted video to the operator's own channel/account.
07

Retention & deletion

Downloaded video files, cached captions, and access tokens remain on the operator's local machine until manually deleted. Deleting the application's data folder removes all of it immediately. Disconnecting a platform in the dashboard removes its stored access token. Revoking access from within Instagram, YouTube, or TikTok's own account settings immediately invalidates the tool's ability to read or post on that platform, independent of this application.

08

Access & control

Because the operator and the account holder are the same person, standard data-subject requests are self-serve:

  • View what's stored — open the local database file directly, or the dashboard's activity log.
  • Delete everything — delete the application's local data folder.
  • Revoke platform access — remove the app's authorization from Instagram, YouTube, or TikTok's respective account/app settings pages.
09

Changes to this policy

If the tool's data handling changes — for example, if a publish-back scope is added in a future version — this page will be updated and the "Effective" date above will change accordingly.
